# Discord Plugins by LGW7

Плагины для Discord, которые я делаю под себя и раздаю друзьям. Тут лежат
только собранные файлы — отсюда их тянет автообновление, качать руками ничего
не нужно.

### YandexMusicRPC

Показывает в статусе, что я слушаю в Яндекс Музыке: трек, исполнителя, обложку
и сколько уже проиграно.

### FakeGameActivity

Ставит в активность любую игру, даже если она не установлена. Время «в игре»
выставляется вручную.

### NotSlowMonitor

Убирает ограничение кадров, когда окно Discord не в фокусе или мышь не
двигается. Заодно не даёт замирать гифкам на втором мониторе.

Если какой-то из них уже стоит, обновится сам: в Discord сверху появится
полоска с кнопкой.

# Discord Plugins by LGW7

Плагины для Discord, которые я делаю под себя и раздаю друзьям.

Чтобы поставить, зайди в папку нужного плагина и скачай оттуда архив — кнопка
скачивания справа над файлом. Распакуй куда угодно и запусти `install.bat`.
Ставить Node.js и что-то ещё не надо, внутри всё уже собрано. Дальше плагин
обновляется сам: когда выйдет новая версия, в Discord сверху появится полоска
с кнопкой.

Папку целиком GitHub скачивать не умеет, поэтому архив и лежит одним файлом.

### YandexMusicRPC

Показывает в статусе, что я слушаю в Яндекс Музыке: трек, исполнителя, обложку
и сколько уже проиграно.

### FakeGameActivity

Ставит в активность любую игру, даже если она не установлена. Время «в игре»
выставляется вручную.

### NotSlowMonitor

Убирает ограничение кадров, когда окно Discord не в фокусе или мышь не
двигается. Заодно не даёт замирать гифкам на втором мониторе.

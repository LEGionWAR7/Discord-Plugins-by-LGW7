# Обновления плагинов Vencord

Здесь лежат свежие версии наборов плагинов. Скачивать отсюда руками ничего не нужно:
установленный плагин `PluginUpdater` сам заглядывает сюда и предлагает обновиться
прямо в Discord.

Для каждого набора — своя папка:

| Папка | Что внутри |
|---|---|
| `YandexMusicRPC/` | Яндекс Музыка в статусе Discord |
| `FakeGameActivity/` | Любая игра в активности, с выбором времени |
| `NotSlowMonitor/` | Снятие ограничения кадров, когда Discord не в фокусе |

В каждой папке `manifest.json` (версия и контрольные суммы) и `dist/` с четырьмя
файлами сборки.

## Как выложить новую версию

1. Запустить `pack.bat` в папке нужного плагина — он спросит, что нового.
2. Содержимое появившейся папки `Publish` положить в одноимённую папку здесь,
   заменив старое.

Всё. У всех, кому набор уже установлен, Discord в течение нескольких часов
покажет полоску с кнопкой «Обновить» — или сразу при следующем запуске.
